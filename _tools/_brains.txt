

========== 土地资源管理/9月4日讲稿.md ==========
[brain start @line 152]

- 土地资源与土地资产课程核心内容
- 土地的基本认知
- 土地是三维空间（含高度与深度）
- 高度由规划限高确定（如80米）
- 深度以日常活动可达范围为界
- 权利类型多样：所有权、使用权、租赁权、抵押权、他项权
- 土地的双重属性
- 自然属性
- 位置固定性（不可移动→不动产）
- 总量有限性→价值递增性
- 自然与历史综合体
- 经济/社会属性
- 利用外部性（如学校提升房价，垃圾厂压低房价）
- 资源与资产双重身份
- 土地分类体系
- 农业用地（耕地、水田、旱地、林地、草地等）
- 建设用地
- 未利用地（沙漠、戈壁、冰川等）
- 土地资源定义与特征
- 定义：可被用于产生经济价值的土地部分
- 理论来源
- 马克思：土地与劳动力为财富原始要素
- 联合国环境署：具经济潜力的自然要素
- 中国土地资源现状
- 总量大（960万km²，世界第三）
- 人均少（全球第110位，耕地仅0.1公顷/人）
- 分布不均（胡焕庸线东侧占1/3面积，2/3人口与耕地）
- 后备资源少
- 耕地质量偏低（最优等仅2.9%，中等以下占70%+）
- 城市土地利用非集约（空城、低容积率问题）
- 土地资产定义与转化
- 定义：具产权归属、可创造经济价值的土地资源
- 转化条件：实体+ 明晰产权
- 并非所有土地资源都可转为资产
- 资产属性在城市尤为突出
- 城市土地特性
- 定义范围：通常指规划区（非仅建成区或行政区）
- 核心特征
- 位置极端重要（区位决定价值）
- 用途相对固定（百年大计，变更成本高）
- 依赖基础设施（路、水、电等构成土地资本）
- 高投入、高产出、高价值
- 利用具节约性（相比农村）
- 建设用地规模绝对扩张（建新城、立体开发）
- 价值跃升机制
- 农地转城市用地→价值暴增
- 基础设施配套费分摊至地价
- 容积率变更可牟利（廉政风险点）
- 中国土地制度基础
- 所有制形式
- 全民所有→国家所有（城市土地）
- 劳动群众集体所有→农民集体所有（农村土地）
- 公有制优越性
- 保障工业化城镇化用地需求（征地高效）
- 维护农村社会稳定（防止失地流民）
- 承包地与宅基地提供社会保障功能
- 三权分置：所有权、承包权、经营权分离
- 关键政策与概念
- 18亿亩耕地红线（粮食安全战略）
- 黑土地保护法（2022年实施）
- 基本农田保护区（湖北首创）
- 发展权缺失问题（对比美国收购发展权模式）
- 补贴实质：对发展权限制的隐性补偿

- 考试形式：开卷但难度高
- 题型：选择、判断、案例分析、论述题
- 禁出：名词解释、简答题等可直接抄书题
- 论述题需深度展开，非简单复述
- 学习目标：具备解决现实法律问题能力
- 民事诉讼法学本质
- 学科定义：研究民事诉讼法规范及实际运行规律
- 区分“民事诉讼法”与“民事诉讼法学”
- 研究对象广义化
- 民事诉讼法典
- 司法解释
- 其他法律中的程序性规范（如民法典第十五条）
- 实体法与程序法关系
- 民法典（实体）需民诉法（程序）保障实现
- 典型案例：欠债不还→起诉→判决→强制执行
- 缺程序法则实体权利无法强制兑现
- 学习方法论
- 理论学习：掌握基本概念与原理
- 实证分析：考察司法实践真实状况
- 上诉率全国仅10%-20%

- 一审裁判实际生效率高

- 四类方式
- 和解（自力救济）：高效灵活但无强制力
- 调解（社会救济）：有第三方介入，稍具公正性
- 仲裁（准司法）：需仲裁协议，裁决具强制力

- 给付之诉：请求给付财物或行为（含隐含确认）
- 变更之诉（形成之诉）：改变现有法律关系（如离婚）

========== 德语/9月4日讲稿.md ==========
[brain start @line 133]

- 德语名词词性与复数规律总结（第20课）
- 名词词性总体分布
- 阴性名词占比最高
- 阳性名词次之（约34%）
- 中性名词最少
- 阳性名词常见类型
- 表男性或男性职业
- 表时间（日、月等，但周为阴性）
- 天气现象（雪、风、雨等）
- 以-al 结尾的人或器具（有例外如Fenster）
- 以-ist 结尾表人（如Polizist, Tourist）
- 以-ling/-ol/-ismus/-ege/-end 等结尾（多为阳性，非绝对）
- 阴性名词常见类型
- 表女性或女性职业（尤以-in 结尾）
- 以-a 结尾（如die Sonne,有例外）
- 以-ung/-heit/-keit/-schaft/-ae/-ion/-ur/-tät/-ei/-anz/-enz 等结尾
- 学科类（-ie 结尾，如Philosophie, Chemie）
- 中性名词常见类型
- 幼小生物（das Kind, das Baby）
- 动词名词化（das Essen, das Lernen）
- 不可分前缀ge-表集合（das Gemüse, das Getränk）
- 以-lein/-chen/-ment/-ma/-um/-o 结尾（如Mädchen, Museum）
- 多数外来词为中性
- 名词复数构成规律
- 单复同行（无词尾变化）
- 多见于-al/-an/-ai 结尾阳/中性名词
- 所有-line/-ment 结尾中性名词
- 加-a（或变元音加-a）
- 多为单音节阳性名词（如der Tag →die Tage）
- 少量阴/中性名词（如die Bank →die Bänke）
- 加-er（或变元音加-er）
